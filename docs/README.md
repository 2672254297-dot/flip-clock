# Flip Clock（翻页时钟 + 空闲屏保）

全屏翻页时钟，精确到秒（`HH:MM:SS`），支持在线改色；并带一个 **Windows 系统级「空闲屏保」宿主**：
**电脑 10 分钟没有鼠标/键盘输入，自动全屏置顶跳出翻页时钟；一有任何输入，淡出并回到桌面。**
**按住 Alt 时屏保不会退出，可以直接在屏保界面上改配色并实时预览。**

> 快速上手看 [`启动指南.md`](../启动指南.md)；本文件讲原理、参数、安全边界与实测记录。
>
> 效果图在 [`previews/`](../previews/)；`tests\selftest-*.png` 由自测运行时现场生成，不入库。

## 二、快速开始

### A. 屏保模式（自动跳出）

1. 双击 **`start.bat`**（想后台静默运行就用 `start-silent.vbs`）。
   - 控制台会打印：设置页地址、空闲阈值、窗口模式、显示屏幕；
   - 同时会在屏幕外预热一个 **kiosk 全屏**窗口（时钟本体），等待被唤醒。
2. 双击 **`settings.bat`** 打开配置页，可调：
   - **背景**：纯色 / 本地图片 / 图片 URL + 0–90% 蒙版；
   - **卡片**：一个基色，上下明暗、冒号、中缝自动推导；
   - **数字**：颜色 + 辉光；
   - **空闲跳出**：启用开关、空闲时长（**10 秒 – 60 分钟**，默认 10 分钟，滑杆按秒调；旁边有 `30 秒 / 1 分 / 5 分 / 10 分 / 30 分` 快捷按钮，测试时直接点 **`30 秒`**）、显示屏幕（鼠标所在屏幕 / 主屏 / 全部屏幕），并显示当前已空闲秒数、窗口模式与浏览器策略。
3. 之后就不用管了：空闲到点自动跳出，一动鼠标/键盘立刻淡出。
4. 不想用了：**`stop.bat`**（或 `clean.bat` 顺带清缓存）。

### B. 手动模式（现在就全屏显示，不监控空闲）

双击 **`clock.bat`**（或 `clock-silent.vbs`，或 `python app\flipclock_overlay.py --manual`）：

- **立即**全屏显示，**不监听空闲时间、不会自动跳出、也不会因鼠标移动自动退出**；
- 不需要按 `Alt`：鼠标靠近右上角就出现齿轮，随时改配色并实时预览；
- 退出：**按 `Esc`**（或 `Alt+F4`、`stop.bat`）；宿主会把时钟浏览器一起清理掉。

> 手动模式与屏保模式共用同一个端口/实例，所以切换前先 `stop.bat`。

### C. 全屏期间隐藏鼠标箭头（全局）

**只要时钟铺满屏幕，鼠标箭头就自动隐藏**，三种情况都生效：

| 场景 | 指针行为 |
| --- | --- |
| 屏保跳出 | 隐藏；按住 `Alt` 或光标停在设置面板内才显示 |
| 手动模式 | 隐藏；**动一下鼠标显示 3 秒**，然后自动隐藏 |
| 网页/`index.html` 按 `F11` 全屏 | 隐藏；动一下鼠标临时显示（1.5 秒后自动隐藏） |

两层保险：宿主侧 `ShowCursor`（循环压到负数，避免别的程序把计数抬回来）+ `SetCursor(NULL)`，
页面侧 `html.nocursor { cursor: none !important }`。页面会把「我有没有隐藏指针」回报给宿主
（`/__state.page.nocursor`），所以自测能直接断言这一点。不想要就用 `--no-hide-cursor` 启动。

### 想快速验证（30 秒跳出）

双击 **`test-30s.bat`**，然后别碰鼠标键盘，30 秒后就会全屏跳出（`--idle-seconds 30` 只覆盖这次运行，不改 `config.json`）。
想一把梭验证全部链路（含全屏/置顶/无白边/指针隐藏/退出/面板保持/手动模式/进程清理）：`python tests\selftest.py`。
更细的步骤、排错表见 **`启动指南.md`**。

### 屏保跳出时怎么调？

屏保全屏显示时**按住 `Alt`**：

- 屏保不再自动退出，鼠标指针恢复显示；
- 右上角出现齿轮、底部出现提示条，点齿轮即可打开设置面板；
- **面板打开后就可以松开 Alt 了**：只要鼠标还在设置面板（或齿轮）范围内，屏保就一直保持不退，可以慢慢调、慢慢看预览；
- 改配色时后面的时钟**实时预览**，改完立即写入 `theme.json`，下次跳出照样生效；
- **鼠标移出面板范围的那一刻，退出立即生效**，屏保淡出回到桌面（关闭面板、按 `Esc`、点 `×` 同理）。

底部提示条会跟着状态切换：按住 Alt 时是「`Alt` 已按住 · … · 松开 Alt 后移动鼠标即退出」；进入面板保持状态后是「设置面板已固定 · 无需按住 Alt · 鼠标移出面板即退出屏保」（见 `previews\preview-overlay-panel.png`）。

## 三、命令行参数

```
python app\flipclock_overlay.py [选项]

--manual             手动模式：立即全屏显示，不监听空闲、不自动退出（Esc 退出、指针动一下显示）——即 clock.bat
--idle-minutes N     空闲多少分钟后显示（覆盖 config.json）
--idle-seconds S     按秒设置空闲阈值（临时覆盖，不写 config.json）——测试常用：--idle-seconds 30
--monitor MODE       cursor（鼠标所在屏幕，默认）| primary | all
--window-mode MODE   kiosk（默认，真·无边框全屏）| app（带标题栏的普通应用窗口）
--keep-browser       常驻预热浏览器（默认，跳出 0 延迟）
--on-demand          按需启动：平时不占内存，退出即彻底结束浏览器
--port N             本地服务端口（默认 8756，被占用会自动顺延）
--browser PATH       指定浏览器（默认自动找 Edge → Chrome）
--no-browser         只跑本地服务，不启动时钟窗口
--dry-run            只跑状态机，不真的显示/隐藏窗口（调试用）
--no-hide-cursor     全屏时不隐藏鼠标指针
--idle-source FILE   测试专用：从文件读空闲秒数，替代系统 GetLastInputInfo（自测用，保证可复现）
--print-url          打印配置页地址后退出
--stop               停止正在运行的实例并清理时钟浏览器
```

`config.json` 字段一一对应：`enabled` / `idleSeconds`（秒，默认 600；>0 时以它为准，测试可填 30）/ `idleMinutes`（旧字段，仅当 `idleSeconds<=0` 时回退）/ `monitor` / `port` / `browser` / `windowMode` / `keepBrowser` / `prewarmSeconds`。

> `--idle-seconds` / `--idle-minutes` 只是**本次运行的临时覆盖**，不写进 `config.json`；
> 一旦你在设置页里改了空闲时长，宿主会自动取消命令行覆盖并打印
> `设置页修改了空闲阈值（idleSeconds）→ 已取消命令行 --idle-seconds 的临时覆盖`，
> 免得出现「改了设置页却没反应」。

## 四、真·全屏是怎么做到的

之前会有标题栏（含名称、最小化/恢复/关闭）和白色边框，原因有两个，现在都已解决：

1. **窗口自带的标题栏**：普通应用窗口的边框由 Chromium 自己管理，用 `SetWindowLong(WS_POPUP)` 去掉后会被它重新加回来。
   → 现在默认用 **`msedge --kiosk`** 启动：Chromium 原生全屏，**没有任何边框、按钮、白边**，任务栏也被盖住。
2. **首次运行的白色登录/同步对话框**：独立 profile 第一次启动时 Edge 会弹「在所有设备上同步你的浏览数据」。
   → 现在启动前会**预置 profile**（`Local State` 写入 `first_run_complete / signin.allowed=false / sync.requested=false`，并创建 `First Run` 标记文件），并附带 `--no-first-run --disable-sync --disable-features=msEdgeIdentityFeatures,...`，实测启动后是纯黑无弹窗。

窗口随后会被 `SetWindowPos(HWND_TOPMOST, 0, 0, 1920, 1080, ...)` 摆到目标屏幕并置顶，实测日志：`已全屏显示：1920x1080 @ (0,0)`。

如果哪天 kiosk 模式在你的机器上有兼容问题，可以用 `start.bat --window-mode app` 退回应用窗口模式（该模式下仍会尝试去边框，但不保证所有 Edge 版本都吃）。

## 五、工作原理

- **空闲判定**：`user32.GetLastInputInfo()` 返回系统级「最后一次输入」的 tick，**任意鼠标或键盘输入都会重置**，因此在别的软件里动一下鼠标也会立刻退出屏保。
- **Alt 豁免**：`GetAsyncKeyState(VK_MENU)` 全局读 Alt 状态；Alt 按住期间不做「空闲退出」判定，并把鼠标指针恢复出来。状态通过 `/__state.alt` 下发给页面，页面据此显示齿轮与提示条。
- **面板豁免**：面板打开后，页面每帧判断光标是否落在面板（或齿轮）矩形内；在面板内就 `POST /__hold {hold:true}` 声明「保持显示」并每秒续期，宿主侧 3 秒超时（页面卡死也不会永久卡住屏保）。光标移出面板 → `hold:false`，紧接着的那次鼠标移动就会触发正常的淡出退出。两条豁免是「或」的关系：`held = Alt 按住 or 面板保持中`。宿主会在日志里记录保持状态的来源，以及在两者之间切换，例如 `⏸ 保持显示（Alt 已按住）` → `⏸ 保持显示来源切换 → 设置面板使用中`（Alt 松开了，但面板在接管，屏保不退）→ `▶ 保持解除 → 移动鼠标即退出`。
- **控制通道**：宿主起一个只监听 `127.0.0.1` 的小 HTTP 服务。
  - `/__state`：页面每 200ms 拉一次；`visible` 变化时执行淡入（600ms）/ 淡出（320ms），`alt`、`hold`、`themeRev` 也在这里同步；
  - 淡出结束后页面 `POST /__ack`（在 `transitionend` 时发，另有 500ms 兜底），宿主收到后才隐藏窗口 —— 先淡出、再消失，不会硬切；宿主最多等 1.2 秒，超时也会隐藏（页面卡死不会把屏保钉住）；
  - `/__hold`：设置面板使用中的「保持显示」声明（带超时续期）；
  - `/__config`：配置页读写空闲设置；
  - `/__theme`：配色读写。**宿主是配色的权威源**（存 `theme.json`），页面启动时拉取、改动时回写、`themeRev` 变化时自动重新应用，所以预热窗口和你的普通浏览器看到的是同一份配色。
- **健壮性**：浏览器冷启动期间触发会稍后自动重试；窗口被意外关掉会自动重新拉起；kiosk 模式窗口无标题，改为「标题匹配 + 按 profile 进程归属匹配类名 `Chrome_WidgetWin_1`」双重定位；端口被占用会用 `connect` 探测（Windows 的 `SO_REUSEADDR` 会让 bind 探测误判）并自动顺延；已有实例在跑会拒绝重复启动。

### 本地控制接口（协议）

接口的**单一数据源**是 `flipclock_http.py` 里的 `API_CONTRACT`（列表形式，含 method / path / auth / body / desc）。
本表就是它的文档副本；`selftest.py` 第 11 阶段会逐项按表断言（无 token 必须 403、带 token 必须可用、
只读接口必须 200），**新增接口忘了登记、或登记了没实现，都会被测出来**。

| 方法 | 路径 | 鉴权 | 请求体 | 语义 |
| --- | --- | --- | --- | --- |
| GET | `/__state` | 无 | - | 全量状态：`visible`/`alt`/`hold`/`cursor`/`manual`/`page`/`themeRev`/`idle`/`threshold` |
| GET | `/__config` | 无 | - | 当前配置（`config.json` 内容） |
| GET | `/__theme` | 无 | - | 当前配色 + `themeRev`（页面据此判断要不要重拉） |
| GET | `/__ping` | 无 | - | 存活探测（宿主用它识别端口上是否已有实例） |
| POST | `/__hold` | **token** | `{"hold": true}` | 页面声明「保持显示」（设置面板使用中），宿主 3 秒超时 |
| POST | `/__ack` | **token** | - | 页面确认淡出动画已结束，宿主可以隐藏窗口 |
| POST | `/__page` | **token** | `{"manual":bool,"nocursor":bool,"panel":bool}` | 页面回报自身 UI 状态（供日志与自测核对） |
| POST | `/__exit` | **token** | - | 请求退出宿主（手动模式按 Esc / 关窗口） |
| POST | `/__config` | **token** | `{"enabled":bool,"idleSeconds":int,"monitor":str}` | 修改配置；阈值夹到 `[MIN_IDLE_SECONDS, MAX_IDLE_SECONDS]` |
| POST | `/__theme` | **token** | `{"bg":"#RRGGBB","img":str,"mask":int,…}` | 修改配色；非法取值被清洗忽略 |

「鉴权=无」的只读接口仍需通过 Host / Origin 白名单；静态资源（`/`、`/index.html`、白名单图片）不在控制接口之列。

### 安全边界（本机服务只服务于本机页面）

控制通道虽然只监听 `127.0.0.1`，但**本机端口对浏览器里的任意网页也是可达的**，所以加了四道限制：

| 限制 | 做法 | 挡住什么 |
| --- | --- | --- |
| **Host 白名单** | `Host` 必须是 `127.0.0.1` / `localhost` / `::1` | DNS 重绑定（用域名连到本机端口） |
| **Origin 白名单** | 带 `Origin` 时必须等于 `http://127.0.0.1:<port>` 或 `http://localhost:<port>`；CORS 只**回显自身来源**，不再发 `Access-Control-Allow-Origin: *` | 恶意/被挂马网页的跨站读取与跨站写（CSRF） |
| **token 鉴权** | 改状态的接口（`/__config`、`/__theme`、`/__hold`、`/__ack`、`/__exit`、`/__page`）必须带 `X-FlipClock-Token`，值 = 本次运行的随机 token（写在 `runtime.json`，启动日志、`--print-url`、`settings.bat` 都会带上；页面 URL 里是 `?t=<token>`） | 其它程序/网页伪造请求改配置或关屏保 |
| **静态文件白名单** | 只服务 **`app\` 下的单个文件名**：仅 `index.html`（截图与文档已移出 `app\`，因此不在可服务范围内）；不递归、不接受子目录 | 任意文件读取（含 `//C:/Windows/...` 这类绝对路径绕过）与 `.edge-profile` 浏览器数据外泄 |
| **请求体上限** | 单个请求体 ≤ `MAX_BODY`（4 MB），超限 **413**；`theme` 取值还要过校验：颜色必须 `#RRGGBB`、`mask` 夹到 0–100、`img` ≤ 2 MB | 超大请求打爆内存、非法配置写坏 `theme.json` |

> token 只出现在 `?t=`、`runtime.json`、启动日志与设置页地址里；**窗口标题用的是独立的非敏感 `w=<tag>`**
> （`FlipClockOverlay-<tag>`），这样同机进程枚举窗口标题也拿不到鉴权凭证。
> `MAX_BODY` 特意大于图片上限：设置页把本地图片以 dataURL 整张 POST 过来，卡太紧会让「换背景图」直接 413。
> 宿主启动时会跑一次 `check_limits_consistent()` 自检，两者关系被写错会在日志里告警（并有自测断言兜底）。

直接访问 `http://127.0.0.1:8756/`（不带 token）会 **302 自动补上 token** 再打开页面，所以手动敲地址也能正常用设置页。
以上每一条都有自测断言（`selftest.py` 第 8/9 阶段），服务端逻辑被改坏会立刻测出来。

## 六、关于「按需启动 / 不常驻内存」

**可以做到，接口已经留好并实测过**（默认关闭，用 `start.bat --on-demand` 或把 `config.json` 的 `keepBrowser` 改成 `false` 即可开启）：

- 宿主（Python，约 25–35 MB）**始终常驻**，这就是「保留监测」的部分——不常驻就没人能读系统空闲时间；
- 浏览器**只在空闲接近阈值时才拉起**（`prewarmSeconds`，默认提前 20 秒），平时完全不占内存；
- **一旦检测到输入、屏保退出，就 `taskkill /T` 彻底结束浏览器进程**，内存立即归还；
- 代价：每次跳出前有 20 秒预热窗口，正常使用感知不到；如果你在阈值前回来，预热会被回收，下次再来重新预热。

也就是说：**移动鼠标后完全终止 = 只杀浏览器，Python 继续监测；真要「连 Python 都退出」就没人监测了**（Windows 上唯一的例外是把程序注册成系统屏幕保护程序 `.scr`，由系统在空闲时拉起它，那种方案可以做「零常驻」）。

## 八、时钟本体的实现要点

- **背景**：默认纯黑全屏；支持纯色、背景图片、图片蒙版。
- **卡片**：6 个深灰圆角矩形，正中间一条 1px 深色水平中缝模拟翻页接缝；上半比下半略亮，营造极微弱的立体感。
- **数字**：纯白默认色，`'Helvetica Neue', Helvetica, Arial, monospace` 系无衬线字体，`font-weight: 200` 细长字重，`font-variant-numeric: tabular-nums` 等宽数字，水平垂直居中。
- **冒号**：两个垂直排列的深灰圆角小方块，常亮不闪烁。
- **翻页动画**：每张卡片 4 层 —— 上半静片、下半静片、上半翻页片、下半翻页片：
  - 数字变化时上半静片立刻换成新数字（被翻页片遮挡），下半静片保持旧数字；
  - 旧数字上半片以 `transform-origin: 50% 100%` 从 `rotateX(0)` 翻到 `rotateX(-90deg)`；
  - 新数字下半片以 `transform-origin: 50% 0%` 从 `rotateX(90deg)` 翻到 `rotateX(0)` 覆盖下半；
  - `perspective` + `transform-style: preserve-3d` + `backface-visibility: hidden` 实现真 3D 透视，`::after` 黑色遮罩动画模拟光影；
  - 动画结束后静默替换下半静片内容，保证下一次翻页状态正确。
- **计时**：`setTimeout` 对齐整秒（`1000 - Date.now() % 1000`），无累积漂移；页面重新可见时立即重新同步。
